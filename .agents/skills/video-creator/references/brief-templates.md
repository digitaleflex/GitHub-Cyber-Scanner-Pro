# Brief Templates — 8 Video Types

Use these as starting structures. Fill in the blanks from the user's context.

---

## 1. SaaS / Product Launch (30s)

```
SUBJECT:   [Product name] — [one-line description]
AUDIENCE:  [Developer / SMB / Enterprise] teams who [pain point]
PLATFORM:  Website hero + social
TONE:      [Authoritative / Energetic / Technical]
DURATION:  30s

SCRIPT SKELETON:
Hook:    "[Pain state]. [Product] changes that."
Story:   "[Product] is [category]. [Key differentiator in one sentence]."
Feature: "[Feature 1]. [Feature 2]. [Feature 3]."
Proof:   "[Stat 1]. [Stat 2]. [Outcome]."
CTA:     "[Product]. [URL]."

SCENES:
1. Pain (0–5s)      Terminal chaos / frustrated user / broken flow
2. Reveal (5–9s)    Product name SLAMS in, scribble underline on key phrase
3. Feature (9–17s)  3 brutalist feature cards cascade
4. Proof (17–22s)   3 stat blocks with burst lines
5. CTA (22–30s)     Full accent-color, circle ring, URL
```

---

## 2. Enterprise Platform Pitch (45–60s)

```
SUBJECT:   [Platform] — orchestration / governance / automation
AUDIENCE:  CTO, VP Engineering, Head of Product at 200+ person companies
PLATFORM:  Sales deck, conference, website
TONE:      Authoritative, measured, cinematic

SCENES:
1. The Problem (0–8s)   Pain statement + terminal error blocks
2. The Platform (8–13s) Platform name + "orchestration layer" framing
3. Orchestration (13–22s) Live diagram: Human → Agent → Gate → Agent → Human
4. Proof Stats (22–27s) 100% audit trail / 10× faster / 70% risk reduction
5. Scale (27–38s)       Org chart of agents + human roles
6. CTA (38–45s)         "Book a demo" + URL

VOICE: bm_george (British male, authoritative)
VISUAL: Velvet Standard or Deconstructed style
```

---

## 3. Developer Tool / CLI (20s)

```
SUBJECT:   [Tool name] — [what it does in 5 words]
AUDIENCE:  Software engineers, DevOps, platform teams
TONE:      Direct, technical, no fluff

SCENES:
1. Hook (0–4s)     Big claim. Dark grid. Monospace everything.
2. Demo (4–14s)    Terminal typing animation. Command runs. Output appears.
3. CTA (14–20s)    "npm install [tool]" types on. GitHub URL.

VOICE: am_adam (neutral, clear)
VISUAL: Deconstructed + Space Mono dominant
```

---

## 4. Product Feature Explainer (30s)

```
SCENES:
1. Problem (0–6s)   "Before: [frustrating state]"
2. Feature (6–20s)  Step-by-step UI walkthrough, 3–4 steps
3. Result (20–25s)  Before/after stat comparison
4. CTA (25–30s)     Try the feature → URL

VOICE: bf_emma (clear, tutorial-friendly)
```

---

## 5. Event / Conference Teaser (15s)

```
SUBJECT:   [Event name] — [date] — [location or "virtual"]
AUDIENCE:  Target attendees
TONE:      High energy, anticipation

SCENES:
1. Hook (0–3s)    Date + location SLAMS in. Staggered text.
2. Why (3–9s)     3 reasons to attend (icon + text per row)
3. CTA (9–15s)    "Register now" → URL

VOICE: af_sky (energetic)
VISUAL: Maximalist Type style
```

---

## 6. Brand / Company Intro (30s)

```
SUBJECT:   [Company] — [what they do]
AUDIENCE:  Prospective customers, partners, investors
TONE:      Premium, purposeful

SCENES:
1. Manifesto (0–6s)   One bold statement. Full frame. Slow reveal.
2. What we do (6–15s) 3-column layout: service/product areas
3. Why us (15–22s)    3 differentiators with supporting copy
4. CTA (22–30s)       "[Company]. [URL]."

VOICE: bm_george or bf_emma
VISUAL: Velvet Standard (luxury/premium) or Shadow Cut (dramatic)
```

---

## 7. Social Media Ad (15s)

```
DURATION: 15s (hook in first 2s)
FORMAT:   1920×1080 landscape or adapt for 1080×1920 portrait

SCENES:
1. Hook (0–3s)   Visual shock / bold claim / question
2. Benefit (3–10s) ONE core benefit shown, not listed
3. CTA (10–15s)  "Try free" / "Shop now" / URL

RULE: No more than 3 sentences total in the entire video.
VOICE: af_sky or af_heart (short, punchy delivery)
VISUAL: Maximalist or Folk Frequency
```

---

## 8. Investor / Startup Pitch (60s)

```
SCENES:
1. Market pain (0–8s)    Big number + problem statement
2. Solution (8–16s)      Product name + one-line differentiator
3. How it works (16–28s) 3-step process diagram
4. Traction (28–38s)     Key metrics: ARR, customers, growth %
5. Team (38–46s)         Founders + key hires
6. Ask / CTA (46–60s)   "Join us at [URL]"

VOICE: bm_george or am_michael
VISUAL: Data Drift (futuristic AI) or Velvet Standard (premium)
```

## Scene Count by Duration

| Duration | Scenes | Avg per scene |
|----------|--------|---------------|
| 15s      | 3      | 5s            |
| 30s      | 5–6    | 5–6s          |
| 45s      | 7–8    | 5–6s          |
| 60s      | 8–10   | 6–7s          |

Never pad a scene with static holds. Every second earns its place.
