## Script Writing Rules

1. **First sentence = hook.** The viewer decides in 3 seconds. Make it a bold claim, contrast, or provocation.

2. **One idea per sentence.** Long sentences break TTS rhythm and make timing harder.

3. **Write the pause.** Short sentences separated by blank lines = TTS breath = visual breathing room.

4. **Say the URL last.** Always the final line. Never mid-video.

5. **Brand name = exact.** Write it exactly as TTS should say it: `CyberAgent` not `Cyber Agent`.

6. **Numbers as words:** `10x` → `ten times`, `$2.3B` → `two point three billion dollars`

7. **Abbreviations spelled out:** `API` → `A P I` (spaces force letter-by-letter), `AI` → `A I`

8. **Test out loud.** Read the script at normal speaking pace. If it sounds robotic, rewrite.

## Pacing Math

```
Target duration (s) × 2.5 wps = target word count

15s → 37 words
20s → 50 words
30s → 75 words
45s → 112 words
60s → 150 words
```

Subtract 10–15% for natural pauses and transition breathing.
